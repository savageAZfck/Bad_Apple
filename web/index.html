Welcome to Bad Apple

Your sovereign, local AI runs entirely on this Mac. No cloud, no subscriptions, and your data never leaves the machine.

  • Chat — ask questions, run local tools, generate images.
  • Persona — switch voices and edit the system prompt.
  • Settings — set workspace, add MCP servers, toggle modes.
  • Dashboard — watch memory, models, P2P, and performance.

Set your workspace

Pick a project folder Bad Apple should know about. Leave it blank and set it later from Settings.

Choose your power-ups

Enable the features you want. You can always change these in Settings later.

Load your models

Bad Apple can use a tiny 0.5B model for quick chitchat, a 9B model for deep reasoning, a 2B vision model, and a 4B FLUX model for local images.

Open the Models page to pre-download them. Otherwise the 9B brain will download the first time you ask a deep question.
